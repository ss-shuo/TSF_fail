# DIET Reference：离散秩区间证据迁移的思想、实验结论与创新复盘

**方法简称：DIET（Discrete Rank-Interval Evidence Transfer，离散秩区间证据迁移）**  
**复盘日期：2026-09-13；证据阶段：预定训练、机制对照、独立校准和最终测试均已完成。**

本文是一份独立的研究经验档案，保留理解方法所需的任务定义、关键公式、对照含义、主要结果与后续设计原则。阅读无需原方案、代码或图表附件。实验数值来自本项目已完成的冻结结果；解释性推断与未来建议另行注明。仅保留本文后，可复用研究思想和核对本文内部论证；逐样本重算和原运行复现仍需要原始预测及实现。

## 1. 最值得记住的结论

DIET 的出发点是：**新站点的数据虽少，却能告诉我们通用预测器最近“怎样预测错了”；把这些错误转成概率尺度上的证据，再按当前预测问题选择相关历史，用来修正完整预测分布。**

最终结果支持这条适应思路。最值得借鉴的是“冻结基础预测器—因果生成历史概率证据—按查询选择证据—在合法支持上输出分布”的组织方式，以及通过匹配对照定位收益来源的研究设计。

原始创新设想更强：离散观测对应一个秩区间，精确使用整个区间应当优于把它压成一个 PIT 点。**这项独立优势没有建立。** 精确区间 DIET 与匹配的点 PIT 方法在两个测试期、校准前后的四组总体比较中，dCRPS 差值的 95% 区间全部跨零；包含点 PIT 的最强预设对照门槛也全部未通过。

因此，这个项目应保存为：**一项有效的短历史概率适应方案，以及一次“整体有效，但最初命名所强调的核心表示增量未获证实”的创新复盘。**

| 判断对象                                   | 最终判断                   | 以后如何使用                                 |
| ------------------------------------------ | -------------------------- | -------------------------------------------- |
| 查询条件化的历史概率证据加权               | 本任务的匹配对照支持其价值 | 值得迁移到其他短历史适应问题                 |
| 精确秩区间优于点 PIT                       | 独立收益未建立             | 可作为概率建模选择，不能写成已验证的性能来源 |
| 相对简单局部校准的整体收益                 | 两个测试期总体 dCRPS 支持  | 值得保留，但同时涉及权重和更新机制差异       |
| 首创注意力、CDF 校准、区间似然或 Beta 变换 | 这些构件已有先行工作       | 创新论证必须解释新的信息接口与可验证增量     |
| 跨城市、严重缺失、全部跨度均优             | 当前证据不支持             | 新任务需要独立验证                           |

## 2. 方案究竟解决什么问题

### 2.1 任务与术语

任务是预测**训练时未见过的电动汽车充电站点，在未来某一小时有多少个连接器处于占用状态**。目标是状态快照中的占用数，不是充电电量、到达车辆数、排队人数或潜在未满足需求。

| 术语             | 本文含义                                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| 容量 $C$         | 一个站点的总连接器数；目标 $Y$ 只能取整数 $0,\ldots,C$                                          |
| 概率质量函数 PMF | 为每个合法计数分配概率，所有概率之和为 1                                                        |
| 累积分布函数 CDF | $F(y)=P(Y\le y)$                                                                                |
| 概率锚点         | 先在源站点训练、随后冻结的基础预测器                                                            |
| 支持窗           | 当前预测起点之前允许使用的最近 168 个小时槽                                                     |
| 查询             | 当前要预测的未来时刻及其已知条件，如小时、星期、预测跨度                                        |
| 因果回放         | 回到支持窗中的较早时刻，仅用当时已经发生的信息预测后来已观测的标签                              |
| PIT              | Probability Integral Transform，概率积分变换；离散观测在 CDF 上对应区间，可在区间内生成随机秩点 |
| few-shot         | 新站点允许使用一段短历史；本实验是滚动一周历史适应，并非只有一两个观测                          |
| 校准             | 调整预测概率与实际频率的对应关系；完整分布评分还同时衡量预测集中程度和误差                      |

数据为 UrbanEV，采用 Dryad 公开版本 423269，发布日期为 2026-02-04。原始观测覆盖 2022 年 9 月至 2023 年 2 月，共 1,682 个站点 ID；按相同坐标字符串分组得到 1,543 组。坐标组整体划分到源、验证、校准和测试池，同组 ID 不跨池，原序列不合并。分组减少近重复身份泄漏，但不等于已经准确识别所有物理站点。

### 2.2 必须和结果一起保存的协议

| 项目       | 实际设定                                                                      |
| ---------- | ----------------------------------------------------------------------------- |
| 小时目标   | 精确抽取每小时 HH:55 的 busy 快照；不对五分钟占用数求和                       |
| 发布时间   | 每日 05:55、11:55、17:55、23:55；采用 Asia/Shanghai 时区假设                  |
| 预测范围   | 未来 1–6 小时，输出六个边际 PMF                                               |
| 输入       | 最近 168 小时的占用数与缺失掩码、容量、已知日历；主情节至少有 24 个有效历史槽 |
| 外生信息   | 主模型不使用未来实况天气、未来价格、坐标距离或外部数据                        |
| 缺失处理   | 缺失输入与真实零值分开；缺失标签不插补、不参与评分                            |
| 源锚点训练 | 源站点，2022-09-01—10-31                                                      |
| 适配器训练 | 同一源站点池，2022-11-08—11-30；锚点冻结                                      |
| 验证与选择 | 独立验证站点，2022-12-01—12-31                                                |
| 独立后校准 | 独立校准站点，2023-01-01—01-14                                                |
| 最终主测试 | 测试站点，2023-01-15—01-31                                                    |
| 压力测试   | 同一预定测试池，2023-02-01—02-28                                              |
| 训练重复   | 三个固定种子：20260910、20260911、20260912                                    |

所谓“跨站点”，是共享参数训练未见测试站点、推理时允许其过去一周观测。六个边际分布不提供完整轨迹依赖，因此不能直接计算“六小时内至少一次满站”的准确概率。由于只在有效标签上评分，结果描述有记录状态上的预测质量。

## 3. 创新构想是怎样工作的

### 3.1 先用一个例子理解

假设某站点容量为 10，基础模型给过去一次实际占用数 $y=2$ 的累积概率为：

$$
F(1)=0.20,\qquad F(2)=0.45.
$$

这次观测在模型自己的概率坐标上对应秩区间 $(0.20,0.45]$，宽度 0.25 就是模型原本赋给“占用数为 2”的概率。区间表示模型如何看待这次观测；换到容量不同的站点，仍然可以在共同的 $[0,1]$ 概率尺度上讨论预测偏差。

DIET 准备少量候选校准映射。某个映射如果能更好解释这类历史观测，就会获得更大的权重。预测明天早高峰时，模型还会判断哪些过去记录与这个查询更相关。最后把所选校准映射作用到明天的基础预测分布上。

```text
源站点数据 → 训练并冻结概率锚点
                         ↓
新站点最近 168 小时 → 窗内因果回放 → 历史观测的秩区间证据
                         ↓                     ↓
当前查询的基础 PMF ──→ 查询相关性权重 ──→ 五个校准映射的混合权重
                         ↓
                  容量范围内的完整预测 PMF
```

这里迁移的是**源站点上学到的“如何根据过去概率误差选择校准方式”**；目标站点的实际修正证据由其自己的合法短历史提供。

### 3.2 基础分布与历史证据

锚点采用 CNP-BB，即条件神经过程（Conditional Neural Process）结合 Beta-Binomial 分布头。CNP 编码历史上下文并针对查询输出参数；Beta-Binomial 负责容量有界的离散概率：

$$
p_0(y)=\binom Cy\frac{B(y+\alpha,C-y+\beta)}{B(\alpha,\beta)},
\quad \alpha=\mu\kappa,\quad\beta=(1-\mu)\kappa.
$$

其中 $\mu\in(0,1)$ 控制平均占用比例，$\kappa>0$ 控制分布集中程度，$B$ 为 Beta 函数。该分布是工作假设，不能由此推断实际连接器之间已经满足某种独立性。

支持窗的前 96 槽用于初始化；后 72 槽分成 12 个不重叠的六小时块。每个块只用此前信息预测其六个标签，得到最多 72 条历史回放记录。一个标签只贡献一次，缺失标签跳过，回放不额外索取 168 槽之前的数据。

对有效历史记录 $i$，把实际计数 $y_i$ 写成：

$$
a_i=F_i(y_i-1),\qquad b_i=F_i(y_i),\qquad U_i\in(a_i,b_i].
$$

$U_i$ 是潜在秩，观测只确定区间。宽度 $b_i-a_i=p_i(y_i)$ 由预测分布决定，**不等于 $1/C$**。

### 3.3 五个映射与查询条件化证据更新

设 $G_j$ 是从 $[0,1]$ 到 $[0,1]$ 的单调校准映射，采用五个固定候选：

$$
G_0(u)=u,\qquad G_j(u)=I_u(\xi_j,\zeta_j),
$$

$$
(\xi_j,\zeta_j)\in
\{(1/2,1/2),(2,2),(1/2,2),(2,1/2)\},\quad j=1,\ldots,4.
$$

$I$ 为正则化不完全 Beta 函数。这组映射提供恒等、尾部与中央质量调整、方向偏移等有限修正。

历史记录在候选映射 $j$ 下的概率证据为：

$$
L_{ij}=(1-\epsilon)\,[G_j(b_i)-G_j(a_i)]
+\frac{\epsilon}{C_i+1},\qquad \epsilon=10^{-8}.
$$

小的均匀成分用于数值稳定。随后从源站点学习三部分：查询条件先验 $\pi^0_j(z_q)$、历史与查询的相关性函数 $r_\psi(z_i,z_q)$、每个预测跨度的证据强度 $\eta_h$：

$$
w_{iq}=\frac{m_i\exp r_\psi(z_i,z_q)}
{\sum_\ell m_\ell\exp r_\psi(z_\ell,z_q)},\qquad
\eta_h=8\,\mathrm{sigmoid}(\nu_h),
$$

$$
\pi_{qj}
=\mathrm{softmax}_j
\left[\log\pi^0_j(z_q)+\eta_h\sum_iw_{iq}\log L_{ij}\right].
$$

$m_i$ 表示历史标签是否有效。相关性网络使用过去预测分布的参数、日历、跨度与时间差等特征；历史实际标签通过 $L_{ij}$ 进入更新，相关性打分本身不直接读取它，查询真值也不参与推理。

其直观含义是：**某种修正方式如果能解释与当前查询相关的历史错误，就提高它在当前预测中的权重。**

### 3.4 输出、训练与计算边界

在当前站点容量格点上解码：

$$
p_{\mathrm{DIET}}(y)
=\sum_{j=0}^{4}\pi_{qj}
\left\{(1-\epsilon)
[G_j(F_{0,q}(y))-G_j(F_{0,q}(y-1))]
+\frac{\epsilon}{C+1}\right\}.
$$

映射单调，因而概率非负；端点为 0 和 1，差分望远镜求和得到总质量为 1；只在 $0,\ldots,C$ 上解码，容量外概率为零。无有效回放证据时使用恒等分量回退锚点，数值实现保留同一微小均匀平滑。

适配器在源站点十一月数据上，以查询标签的负对数似然（NLL）训练，锚点保持冻结；新站点推理时只做前向更新，不进行站点参数微调。实际适配器有 3,212 个可训练参数，两个小网络的隐藏宽度为 32，并含六个证据强度参数。

小参数量主要降低学习与适应负担，**总成本仍包含每个支持窗的 12 次锚点回放和完整容量 PMF 枚举**。项目没有据此建立相对所有对照的速度优势。

## 4. 什么属于创新尝试，什么属于已有工具

| 层次                     | 实际内容                                               | 合理定位                                         |
| ------------------------ | ------------------------------------------------------ | ------------------------------------------------ |
| 问题选择                 | 未见站点、短窗、有缺失、容量有界计数预测               | 有意义的研究契约；价值来自真实约束的组合         |
| 共同建模接口             | CNP、Beta-Binomial、容量归一化、因果情节               | 基础方法及共同工程适配                           |
| 原始核心假设             | 用精确离散秩区间承载历史概率误差，并迁移到查询条件更新 | 可证伪的方法增量假设；精确区间独立收益未建立     |
| 获得支持的部分           | 用查询相关性选择短历史概率证据                         | 在本任务中有实证价值；相关性加权本身已有先行工作 |
| CDF 差分与单调变换       | 把离散观测转成区间似然、生成合法 PMF                   | 已有概率理论与校准工具                           |
| 五映射混合与广义证据更新 | 小型、可解释、容量合法的适配层                         | 可复用组合设计；组合不同不自动构成充分新颖性     |

最初叙事把“区间表达更忠实”与“应当带来预测优势”联系得过紧。最终更准确的贡献定位是：**在固定有界计数预测任务中，对查询条件化的短历史概率证据适应进行实现与受控验证。** 若要继续作为新方法发表，还需针对已有条件校准、上下文加权与元学习方法做实质差异比较。

## 5. 实验到底证明了什么

### 5.1 对照的含义比实验编号更重要

| 编号／名称           | 做法                                                       | 要排除的替代解释                         |
| -------------------- | ---------------------------------------------------------- | ---------------------------------------- |
| E1：概率锚点         | 仅用早期源数据训练 CNP-BB                                  | 适配相对基础模型是否有效                 |
| E2：全源数据 CNP-BB  | 用锚点训练池与适配训练池的并集训练基础模型                 | 改善是否仅来自多看了源数据               |

| E6：点 PIT           | 仅把历史区间证据换成固定随机秩点的密度近似；重新训练适配器 | 精确区间接口本身是否有独立增益           |
| E7：查询无关证据权重 | 历史证据权重在六个查询间共享，保留查询条件先验和输出族     | 对当前查询有区别地选证据是否有用         |
| E8：条件先验         | 单独训练只看查询已知条件的混合头，不读回放误差             | 收益是否只是更灵活的条件分布修正         |
| E8：全局校准         | 在源适配池按跨度拟合固定五组件混合权重                     | 简单全局失配能否解释收益                 |

| E9：点预测残差区间   | 保留 E2 预测均值，独立校准绝对残差区间                     | 简单点预测后处理能否提供类似区间表现     |

E5、E6、E7、E8 共用锚点、回放标签、五个校准映射与最终查询组件 PMF。E6 的点化只发生在**历史证据接口**，其最终输出仍然是精确差分得到的合法离散 PMF。E7 只去掉证据选择中的查询差异，整个预测器仍有查询条件。E8 条件先验的锚点也使用合法历史，它去掉的是回放误差更新。

E4 是按本项目数据和信息预算实现的 CAMP 风格结构对照，不能用其分数代表所有 CAMP 版本；E3 同样只代表该固定 DeepAR-BB 配方。E4 与 DIET 同时改变证据表示和最终更新族，因此两者差值无法单独识别秩区间贡献。

### 5.2 指标、校准与统计口径

主指标是原始连接器计数尺度的离散连续秩概率分数：

$$
\mathrm{dCRPS}(F,y)
=\sum_{k=0}^{C}\left[F(k)-\mathbf1(y\le k)\right]^2.
$$

数值越低越好。先在站点内按各跨度汇总有效目标，再平均跨度，最后平均站点，防止记录更多的站点直接主导结果。站点等权不等于容量归一化，本指标保留计数误差的实际尺度。

每个方法、每个训练种子在独立校准池拟合一个全局温度，形式为 $p_T(y)\propto p(y)^{1/T}$，优化 NLL。报告原始和校准后两套结果，不为每个方法事后挑更好的一列。

95% 区间采用 1,000 次配对重采样：空间单位为坐标组，时间单位为所有站点共用的七日循环移动块；每次抽样分别计算三个训练种子再取平均，不把种子算成额外独立数据。主测试只有 17 天，独立时间信息有限；这些区间覆盖本划分内的不确定性，不覆盖所有城市或站点划分。

## 6. 为什么原始“精确区间创新”没有站住

### 6.1 数学上更精确，不自动意味着任务上更有用

精确证据是 $G_j(b)-G_j(a)$；点 PIT 对照使用：

$$
u=a+v(b-a),\quad v\in(0,1),\qquad
\widetilde L_j=(1-\epsilon)(b-a)g_j(u)+\frac{\epsilon}{C+1},
$$

其中 $g_j=G'_j$，$v$ 由训练种子与情节身份确定，避免每次调用重新抖动。对 $U\sim\mathrm{Uniform}(a,b)$，Jensen 不等式给出：

$$
\mathbb E[\log g_j(U)]
\le \log\frac{G_j(b)-G_j(a)}{b-a}.
$$

这说明“取随机点后优化对数密度”和“积分后取对数”通常不同。**它证明的是目标函数之间的关系，不是 DIET 相对 E6 的 dCRPS 优势定理。** 更没有证明优势足以超过训练波动或实际应用门槛。

### 6.2 真正决定更新的是组件之间的证据差异

这是根据公式得到的解释，有助于设计后续实验：

忽略微小平滑时，精确证据可分解为

$$
L_{ij}=(b_i-a_i)\,\overline g_{ij},\qquad
\overline g_{ij}=
\frac{1}{b_i-a_i}\int_{a_i}^{b_i}g_j(u)\,du.
$$

对同一历史记录，$\log(b_i-a_i)$ 在全部组件中相同，进入组件 softmax 时会抵消。因此精确接口的增量主要是：用**区间内平均密度**替代**某个秩点的密度**，从而改变不同校准组件的相对证据。

如果候选密度在相关区间内变化不大，两种接口就可能给出相近的组件选择。区间宽也不必然导致显著差异，还要看映射的局部形状、历史权重与最终预测对组件权重的敏感性。极小概率处的平滑会影响上述近似，不能把抵消关系当成所有数值情形的精确等式。

### 6.3 已知结果与尚未验证的解释应分开

| 状态       | 结论或解释                                                        |
| ---------- | ----------------------------------------------------------------- |
| 已观察     | 精确区间与点 PIT 总体差异很小；四组 dCRPS 区间跨零                |
| 已观察     | 去掉查询相关证据权重、去掉回放误差更新都会降低总体表现            |
| 已观察     | 宽秩区间分层也未稳定建立 E5 对 E6 的优势                          |
| 结构事实   | E5、E6 共用同一五组件输出族，接口差异只能通过组件权重影响最终分布 |
| 待验证解释 | 相关历史中的密度变化不足，使积分与点近似产生接近的相对证据        |
| 待验证解释 | 学到的先验、相关性权重和证据强度吸收了部分接口差异                |
| 待验证解释 | 有限五映射的表达能力限制了精确证据所能转化的收益                  |

后面三项是可能原因，不是本项目已经识别的失败根因。未来应测量“接口差异是否改变组件权重、权重变化是否改变分布、分布变化是否改善目标分数”，逐段建立证据链。

## 8. 不足与不可取做法：哪些已经发生，哪些应避免

### 8.1 方法与研究设计本身的不足

**核心表示的性能必要性不足。** 精确区间有清晰概率语义，但对照显示点化接口也能获得近似表现。后续设计应先确认必须保留区间的情形，再以此组织创新主张。

**校准空间有限且依赖锚点。** 五个预设映射只能在其变换分布的混合范围内修正误差；它们可以改变均值和方差，却不能保证表达任意多峰或工况变化。锚点若长期丢失关键状态信息，适配层可能没有足够的修正能力。该表达限制由结构决定，其是否主导本次误差尚未被验证。

**证据强度没有充分表达样本量与冲突。** 历史权重归一化为和等于 1，$\eta_h$ 只按跨度学习并限制在 0–8。这样避免直接把相关记录机械相乘，但不会自动获得正确的有效样本量；相同内容重复出现也不会像普通独立似然那样成比例增强证据。一个有效标签与几十个标签、相互一致与强烈冲突的历史，可能需要不同适应强度，当前结构没有直接建模完整区别。

**回放与正式查询的上下文条件不完全相同。** 回放从 96 槽前缀逐步增长，正式查询最多使用 168 槽。历史误差同时反映站点失配与上下文长度变化，两者是否影响迁移需要另测。回放设计保证因果合法，并不自动保证历史误差与未来误差同分布。

**训练目标和最终评价权重不同。** 适配器以情节内有效查询的 NLL 训练，最终主指标是站点宏 dCRPS。概率似然改善不必然等同于跨站点评分改善，尤其在容量、缺失率与站点样本数差异较大时。

**“短历史、缺失”动机的实证覆盖不均衡。** 主结果绝大部分来自 120–168 个有效历史槽的情节。现有结果更有力地支持一周较完整历史下的适应，严重稀疏与空证据情形仍缺少足够站点。

**外部效度和基线范围有限。** 单城、六个月、固定站点划分和两个较短测试期，不能支持跨城市外推。E2 匹配了源信息，但“相同 epoch”不意味着两阶段方法与单模型的优化步数或总算力相等；E3、E4 的结果也不覆盖全部强配方。已有条件校准与元学习近邻仍需继续比较。

### 8.2 实际踩过的工程坑

| 已发生的问题                               | 如何识别及处理                                                                                           | 以后应保留的规则                                                              |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |

下列做法是本次复盘明确要避免的推理或决策错误，其中部分已被原实验流程成功阻止，不应误记为本项目实际违规。

| ------------------------------------ | -------------------------------------------- | ---------------------------------------------------- |

| 以更多复杂模块挽救未成立的表示主张   | 改进后的收益仍无法说明原表示为何必要         | 先定位可迁移信号，明确替代解释，再提出新机制         |

## 9. 以后做创新时，如何复用而不重犯

### 9.1 推荐的研究顺序

1. **先写清基线的具体失败。** 例如“同一新站点在某类查询上持续低估尾部概率”，并指出短历史中的什么信息能预示它。仅写“泛化不足、存在不确定性”无法约束方法设计。
2. **先列最强简单解释。** 比较更多源数据、局部均值／尺度修正、全局校准、局部校准和简单查询权重。只需能区分解释的最小实验，不必同时扩张所有路线。
3. **把新表示与其他改动分开验证。** 如比较秩区间和点 PIT，就固定锚点、输出族、训练池、参数规模和评价协议，使表示差异成为主要变化。
4. **要求增量传递到最终任务。** 检查表示差异、组件权重差异、预测分布差异与实际评分差异。中间量变得更“精确”，不代表最后一环获益。
5. **提前定义接受与停止条件。** 除区间方向外，规定最小有用改进、额外时间／内存预算和关键场景覆盖；没有证据时保留最简单的可用方法。非显著结果不能充当等价性证据。
6. **开发阶段做机制诊断，测试阶段做最终评价。** 合成例子可验证实现和理论预期，真实验证集决定机制是否适合任务；小代理实验不能替代最终模型证据。
7. **按实际证据写贡献。** 若查询加权成立而精确区间优势不成立，就保存前者的经验价值、删除后者的强性能主张。名称可以保留用于追溯，贡献含义必须更新。

### 9.2 可探索的新方向与启动条件

以下是未来研究假设，尚无本项目结果支持。当前最终测试已经揭盲，不能直接用其分数选择这些方案。

| 新方向                       | 真正要回答的问题                             | 启动前的最低证据                                     | 必须保留的简单对照                       |
| ---------------------------- | -------------------------------------------- | ---------------------------------------------------- | ---------------------------------------- |
| 证据数量与冲突感知的适应强度 | 历史少或彼此冲突时，固定跨度强度是否过度适应 | 在独立开发数据上，证据数量／冲突能预示未来修正失败   | 常数强度、按有效记录数收缩、简单近期加权 |
| 按日块处理概率误差           | 同一日内相关记录是否重复表达同一个偏差       | 日块差异对未来误差有预测力，且超过均值／尺度漂移解释 | 全局离散度修正、简单日块平均与时间衰减   |
| 更灵活的受约束校准映射       | 五映射是否确实遗漏了反复出现的分布形状       | 现有族在开发集留下系统失配，局部权重变化无法修正     | 同预算简单扩充、点 PIT 版本、局部校准    |
| 更简单的查询相关证据选择     | 神经相关性网络是否值得其复杂度               | 小时匹配、跨度匹配、时间衰减不能解释已有收益         | 固定日历权重、近期窗口、查询无关权重     |
| 真正的稀疏历史适应           | 低历史优势是否可重复，而非少量站点偶然结果   | 预先设计的稀疏条件下有足够独立站点和真实缺失评价     | 锚点回退、条件先验、简单收缩             |

原方案曾保留 BDER（Block-Disagreement Evidence Revision，日块分歧证据修正）作为备选，思想对应上表第二项。它没有作为本轮最终方法启动，不能将其记作已验证成果。值得保留的是启动判据：**先证明块间分歧能预示未来概率误差，并超过普通尺度修正，再引入分歧处理机制。**

### 9.3 一段可直接复用的项目结论

> DIET 将新站点短历史中的因果预测误差表示为离散秩区间，通过查询相关的广义证据更新选择有限校准映射，并在容量合法的离散支持上输出预测分布。在 UrbanEV 固定站点与时间协议下，它相对全源数据基础模型、查询无关证据权重及全局／局部校准获得总体 dCRPS 改善。匹配的点 PIT 对照获得接近表现，精确秩区间的独立优势和相对全部预设对照的总体优势均未建立。可复用的核心经验是利用查询相关的短历史概率证据进行适应，并用匹配对照判断新表示是否必要。
